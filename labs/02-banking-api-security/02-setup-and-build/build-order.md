# AWS Banking API Security Lab - Build Order

1. Create DynamoDB tables for accounts and transactions
2. Seed test data for User A and User B
3. Create Lambda function for GET /accounts/{accountId}
4. Create Lambda function for GET /accounts/{accountId}/transactions
5. Create Lambda function for POST /transfer
6. Configure API Gateway routes
7. Verify vulnerable behavior
8. Add Cognito authentication
9. Enable CloudWatch logging
10. Simulate attacks
11. Add authorization checks
12. Add AWS WAF rate limiting
13. Re-test and document results
