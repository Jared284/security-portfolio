# Setup and Build

This section will document the AWS environment setup for the IAM least-privilege hardening lab.

Planned build steps:

1. Create the test IAM user.
2. Create the S3 test bucket.
3. Add a test object to the bucket.
4. Attach the initial over-permissive policy.
5. Configure or verify CloudTrail logging.
6. Configure the AWS CLI profile for access testing.
