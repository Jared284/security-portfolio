Security Labs

SSH Brute-Force Detection & Prevention

Lab 01

End-to-end detection engineering lab in a local VirtualBox environment. Simulated SSH brute-force activity against an Ubuntu Server VM, analyzed /var/log/auth.log, and implemented automated IP banning with Fail2Ban. Evolved from manual log triage into time-windowed detection-as-code, mirroring how real blue teams develop detection logic.

Linux Fail2Ban OpenSSH Python Log Analysis Detection Engineering VirtualBox

AWS Banking API Security – BOLA Attack & Remediation

Lab 02

Designed and exploited a deliberately insecure cloud-based banking API on AWS (API Gateway → Lambda → DynamoDB) to demonstrate Broken Object Level Authorization (BOLA / IDOR). Verified unauthorized account access, then hardened the Lambda function with server-side ownership validation and re-confirmed the fix blocked the original attack.

AWS API Gateway Lambda DynamoDB BOLA / IDOR API Security Authorization

Cloud Security Monitoring (CloudTrail + CloudWatch + SNS)

Lab 03

Built a dual-path security monitoring pipeline in AWS. Forwarded EC2 Linux authentication logs into CloudWatch via the CloudWatch Agent, and routed CloudTrail control-plane events through the same platform. Engineered four validated detections — repeated invalid-user SSH attempts, security group ingress rule changes, and IAM managed policy attachments — each wired to CloudWatch alarms and SNS email alerts.

AWS CloudTrail CloudWatch SNS EC2 IAM Detection Engineering SIEM-style Monitoring

AWS IAM Least-Privilege Hardening

Lab 04

Identified and eliminated over-permissioned AWS IAM access. Started with an intentionally broad IAM identity, tested its allowed and risky actions via the AWS CLI, replaced the broad policy with a scoped least-privilege policy, and used CloudTrail to validate both allowed and denied API activity after the change.

AWS IAM S3 CloudTrail AWS CLI Least Privilege Access Control Policy Design
